# Forsa

Forsa est une boutique de vêtements en ligne construite avec React et Vite.
L'interface est disponible en français, anglais et arabe, avec prise en charge du mode RTL.

## Fonctionnalités

- Catalogue, recherche et catégories de produits
- Fiches produit accessibles depuis toutes les cartes
- Navigation dynamique avec React Router
- Zoom des images produit au clic, y compris sur mobile
- Sélecteur de langue français, anglais et arabe
- Interface responsive avec React Bootstrap

## Installation

```bash
npm install
```

## Scripts

```bash
npm run dev      # lancer le serveur de développement
npm run build    # générer la version de production
npm run preview  # prévisualiser la version de production
```

Le serveur de développement est généralement disponible à l'adresse `http://localhost:5173`.

## Technologies

- React 19
- Vite
- React Router
- React Bootstrap
- i18next et react-i18next
- react-inner-image-zoom
